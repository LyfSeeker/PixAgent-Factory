# Hackathon demo guide

## Setup

Run `npm install && npm run dev`, then open the home route. The default studio is preloaded with the **Student Event Management Platform** demo.

## Suggested 90-second story

1. Introduce the office as an observable AI software studio—not a decorative dashboard.
2. Click Maya or Alex to show their current assignment, capacity, skills and editable display name.
3. Click **Run demo project**: explain that the flow surfaces a dependency-blocked QA task and the manager signal.
4. Click it again to show Sara resuming after the API contract becomes available.
5. Open **Tasks** to show work flowing through the factory board.
6. Open **Agents** to show each coworker’s skills and workload.
7. Return to the studio and point to the decision alert: sensitive execution pauses for human approval.

## Audience takeaway

PixAgent Faactory makes parallel AI coding work visible: who is working, what they own, why someone is waiting, where a blocker originates, and when a human needs to decide.
